Wavelength Solution Files
=========================

CRISPY stores its wavelength solution in a plain-text file named ``lamsol.dat``.
Each row contains the calibration for one wavelength, and each row can be used to
map lenslet-array coordinates to detector coordinates.

What ``lamsol.dat`` Contains
----------------------------

Each row has the form:

.. code-block:: text

   wavelength_nm, x-coefficients..., y-coefficients...

- Column 0 is the wavelength in nm.
- The remaining columns are polynomial coefficients for detector ``X`` followed by
  polynomial coefficients for detector ``Y``.
- If the polynomial order is ``p``, the row contains ``(p + 1) * (p + 2)``
  coefficients after the wavelength column.
- Half of those coefficients belong to the ``X`` mapping and half belong to the
  ``Y`` mapping.

For the common case ``p = 3``, there are 20 coefficients after the wavelength
column:

- 10 coefficients for ``X(i, j)``
- 10 coefficients for ``Y(i, j)``

The code infers the polynomial order from the number of coefficient columns using
the relation:

.. math::

   (p + 1)(p + 2) = N_{\mathrm{coeff}}

Coordinate Convention
---------------------

The lenslet indices are usually represented on a centered integer grid. In several
places in the codebase this is constructed as:

.. code-block:: python

   x_lens_ind = np.arange(-nlens // 2, nlens // 2) + 1
   x_lens_ind, y_lens_ind = np.meshgrid(x_lens_ind, x_lens_ind)

That means a lenslet is identified by integer coordinates ``(i, j)`` on the
lenslet array, and ``lamsol.dat`` tells you where that lenslet lands on the
detector at a given wavelength. The '+1' ensures that the lenslet indices are centered around 0 for 
lenslet arrays that contain an odd number of lenslets per side.

Coefficient Ordering
--------------------

The authoritative coefficient ordering is implemented in
``crispy.tools.locate_psflets.transform``.

For polynomial order ``p``, detector coordinates are evaluated as:

.. math::

   X(i, j; \lambda) = \sum_{ix=0}^{p} \sum_{iy=0}^{p-ix} a_{ix,iy}(\lambda) i^{ix} j^{iy}

.. math::

   Y(i, j; \lambda) = \sum_{ix=0}^{p} \sum_{iy=0}^{p-ix} b_{ix,iy}(\lambda) i^{ix} j^{iy}

The coefficients are stored in this order:

1. All ``X`` coefficients
2. All ``Y`` coefficients

Within each block, terms are ordered by increasing ``ix`` and then increasing
``iy`` subject to ``ix + iy <= p``.

For order 3, the term order is:

.. code-block:: text

   1, j, j^2, j^3, i, i*j, i*j^2, i^2, i^2*j, i^3

So a third-order row is interpreted as:

.. code-block:: text

   wavelength,
   X[1, j, j^2, j^3, i, i*j, i*j^2, i^2, i^2*j, i^3],
   Y[1, j, j^2, j^3, i, i*j, i*j^2, i^2, i^2*j, i^3]

Worked Example
--------------

If you want detector coordinates for a wavelength that is explicitly present in
``lamsol.dat``, the direct pattern is:

.. code-block:: python

   import numpy as np
   from crispy.tools.locate_psflets import transform

   lamsol = np.loadtxt(par.wavecalDir + "lamsol.dat")
   wavelengths = lamsol[:, 0]
   allcoef = lamsol[:, 1:]

   order = 3
   i = 0
   j = 0

   row_index = np.argmin(np.abs(wavelengths - 660.0))
   coef = allcoef[row_index]
   x_det, y_det = transform(i, j, order, coef)

For a full grid of lenslets, pass 2D arrays instead of scalar ``i`` and ``j``.

Interpolating Between Tabulated Wavelengths
-------------------------------------------

The preferred code path for arbitrary wavelengths is the ``PSFLets`` helper in
``crispy.tools.locate_psflets``:

.. code-block:: python

   from crispy.tools.locate_psflets import PSFLets

   psftool = PSFLets()
   psftool.geninterparray(wavelengths, allcoef)
   x_det, y_det = psftool.return_locations(657.5, allcoef, i, j)

This fits each coefficient as a function of wavelength and evaluates the mapping
at the requested wavelength. In the current implementation, that interpolation is
performed in powers of ``log(wavelength)``.

Related Files
-------------

``lamsol.dat`` is one part of the wavecal product set generated by
``crispy.tools.wavecal.buildcalibrations``.

Other closely related files are:

- ``PSFloc.fits``: detector-coordinate and wavelength lookup products derived from
  the wavelength solution.
- ``polychromekeyRXX.fits``: per-wavelength lenslet positions and validity mask for
  extraction products.
- ``polychromeRXX.fits``: forward model cubes used for least-squares extraction.

Where This Is Used In The Code
------------------------------

Useful implementation references:

- ``crispy.tools.locate_psflets.transform`` for the coefficient ordering and direct
  polynomial evaluation.
- ``crispy.tools.locate_psflets.PSFLets.return_locations`` for the higher-level API.
- ``crispy.tools.wavecal.illustrate_dispersion`` for an example of reading a
  lamsol file and applying one row of coefficients.
