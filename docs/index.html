🎯 About CRISPY

CRISPY simulates the WFIRST (now Roman Space Telescope) Integral Field Spectrograph with high-fidelity modeling of optical effects, detector characteristics, and data reduction pipelines. This powerful scientific tool enables researchers to model and analyze spectrographic data with unprecedented accuracy.

🔭

High-Fidelity IFS Simulation

Complete modeling of WFIRST/Roman Space Telescope IFS with accurate optical and detector characteristics

🌈

Polychromatic Processing

Full spectral cube generation and analysis across multiple wavelengths

🎛️

Multiple Configurations

Support for WFIRST and PISCES instruments with configurable parameters

🧪

Comprehensive Testing

Modern pytest framework with emoji output and extensive test coverage

📊

Data Reduction Tools

Optimal extraction, wavelength calibration, and advanced analysis tools

🐍

Modern Python

Built for Python 3.8+ with modern scientific computing libraries

🚀 Quick Start

Get started with CRISPY in just a few commands:

# Clone the repository
git clone https://github.com/lanemeier7/crispy.git
cd crispy

# Create and activate conda environment
conda env create -f environment.yml
conda activate crispy

# Install in development mode
pip install -e .

# Test the installation
python test_environment.py
python run_tests.py --working
